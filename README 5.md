# Day 5 – Excel Data Analysis

## Project overview
This project analyzes the Sample Superstore retail dataset using Microsoft Excel.

## Workbook contents
- `Raw_Data` – original dataset
- `Working` – helper columns and formulas for Order Year, Month Name, Year-Month, and Profit Margin
- `Summary` – KPIs, formula-based summaries, and key findings
- `Pivot_Category` – sales and profit by category
- `Pivot_Region` – sales and profit by region
- `Pivot_Monthly_Sales` – monthly sales trend
- `Pivot_Subcategory_Profit` – profit by sub-category

## Key findings
Total sales were $2.30M and total profit was $286.4K. Technology generated the highest sales and profit among categories. West generated the highest regional sales. Tables recorded the largest sub-category loss, so its pricing and discount patterns should be reviewed.

## Tools used
- Microsoft Excel
- Formulas: SUM, SUMIF, YEAR, TEXT, IFERROR
- PivotTables
- Sorting, filtering, and KPI analysis
