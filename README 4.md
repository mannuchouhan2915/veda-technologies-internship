# Day 4 – Data Visualization and Storytelling

## Business question
Sales badhi hain, par kya saare products profit bhi kama rahe hain?

## Story
1. Annual sales trend shows growth from 2014 to 2017.
2. Category profitability compares sales performance with profit.
3. Subcategory analysis highlights loss-making products, especially Tables.
4. Discount review identifies areas to investigate; it does not prove discounts caused the losses.

## Tools
- Microsoft Power BI Desktop
- Power Query
- DAX
